## 仆从是什么

仆从是一个**盔甲架小人**，放置后会在指定范围内**自动采集资源**。它拥有自己的仓库（真实箱子），可以升级、加燃料、装备模块，玩法对齐 Hypixel SkyBlock Minions。

**核心玩法：**
1. 放置仆从 → 它自动在 5×5 范围内采集资源
2. 右键小人 → 打开仓库，取出产物
3. 升级仆从 → 更快的速度、更多功能
4. 加燃料 → 加速产出
5. 装模块 → 自动熔炼、压缩、售卖等

## 获取仆从

管理员可以通过命令发放仆从：

```
/minion give 煤矿仆从 1
/minion give 铁矿仆从 5
/minion give 钻石仆从 1
```

你也可以通过 `/minions` 打开图鉴，查看所有可用的仆从类型。

## 放置与使用

### 放置
1. 手持仆从生成物（物品栏选中）
2. 右键方块放置
3. 生成盔甲架小人，面向你的方向

> **注意：** 同一格不能放两个仆从；仆从之间有最小间距限制。

### 交互
- **右键小人** → 打开仓库界面
- **潜行+右键** → 拾取仆从（仓库/模块/皮肤随生成物保留）
- **手持燃料右键** → 添加燃料（每次消耗 1 个）

### 工作
仆从放置后自动工作，每 20 tick（1 秒）检查一次范围内可采集目标。

**不同仆从的工作方式：**

| 行为 | 工作方式 | 产量取决于 |
|---|---|---|
| 采矿 | 只读方块类型，不破坏 | 范围内矿石数量 |
| 农业 | 读取作物生长阶段，不破坏 | 范围内成熟作物数量 |
| 伐木 | 连锁砍伐整棵树 + 补种 | 范围内树木 |
| 钓鱼 | 附近有水即工作 | 固定 1-2 条/次 |
| 战斗 | 优先击杀真实怪物 | 范围内怪物数量 |
| 畜牧 | 纯模拟（不生成实体） | 固定 1-3 件/次 |
| 生成器 | 生成圆石再采集 | 范围内空间 |

## 仓库界面

右键小人打开 54 格仓库界面，布局如下：

```
┌──────────────────────────────────────────────────────┐
│  燃料槽  │  ▒  │  ▒  │  ▒  │  头颅  │  ▒  │  信息  │  皮肤  │  升级  │
├──────────────────────────────────────────────────────┤
│  模块1  │  ▒  │ ───── 存储区（按 Tier 解锁）───── │
│  模块2  │  ▒  │ ───── 存储区 ─────────────────── │
│  模块3  │  ▒  │ ───── 存储区 ─────────────────── │
│  模块4  │  ▒  │ ───── 存储区 ─────────────────── │
├──────────────────────────────────────────────────────┤
│  ▒  │  ▒  │  ▒  │  ▒  │  收集  │  ▒  │  拾取  │  关闭  │
└──────────────────────────────────────────────────────┘
```

**主要按钮：**

| 位置 | 功能 | 操作 |
|---|---|---|
| 左上 | 燃料槽 | 空手点击打开燃料选择 GUI |
| 中上 | 头颅 | 仆从外观展示 |
| 右上 | 信息卡 | 显示速度/产量/范围/存储等统计 |
| 右上 | 皮肤 | 点击切换皮肤 |
| 右上 | 升级 | 点击打开 3×3 合成升级界面 |
| 左侧 | 模块槽 | 手持模块点击装备/卸下 |
| 中央 | 存储区 | 取放物品（锁定格 = 未解锁） |
| 底中 | 收集 | 一键收取所有产物到背包 |
| 底右 | 拾取 | 收起仆从（生成物回到背包） |

## 升级系统

### 升级方式
1. 右键小人打开仓库
2. 点击右上角「升级」按钮
3. 打开 3×3 合成界面
4. 放入**当前等级仆从本体 + 升级材料**
5. 点击右侧产物合成下一等级

### 升级材料
- 每种仆从有专属配方（在 config.yml 中配置）
- 材料数量随等级递增（陡增曲线）
- 支持附魔资源（如 `附魔煤炭`）作为高级材料
- 稀有掉落可作为高阶升级材料（回流机制）

### 等级效果
- **Lv.1 → Lv.12**：逐级解锁更多存储槽位
- 冷却时间逐级缩短（工作更快）
- 等级越高，升级材料越贵

### 快捷操作
- **潜行点击信息卡**：从背包一键填充合成材料
- **点击指南按钮**：查看材料清单与已有数量
- **关闭合成界面**：格内残留物品自动归还背包

## 燃料系统

> 无燃料时仆从仍工作，燃料只加速。

### ⏱ 速度燃料

| 燃料 | 加速 | 持续时间 |
|---|---|---|
| 煤炭 / 木炭 | +5% | 3 分钟 |
| 煤炭块 | +5% | 15 分钟 |
| 岩浆桶 | +25% | 60 分钟（返还空桶） |
| 烈焰棒 | +30% | 18 分钟 |

### ♾ 永久燃料

| 燃料 | 加速 | 说明 |
|---|---|---|
| 岩浆膏 | +30% | 永久生效，不衰减 |
| 荧石粉 | +35% | 永久生效，不衰减 |
| 日光传感器 | +25% | 永久生效，不衰减 |

### 🧪 催化剂（产量倍率）

| 催化剂 | 倍率 | 持续时间 |
|---|---|---|
| 紫水晶碎片 | ×1.5 | 30 分钟 |
| 烈焰粉 | ×2.0 | 15 分钟 |
| 幻翼膜 | ×3.0 | 8 分钟 |

### 如何加燃料

**方式一：燃料选择 GUI（推荐）**
1. 空手点击仓库左上角「燃料槽」
2. 打开燃料选择界面（自动列出背包中可用燃料）
3. 点击燃料选项 → 消耗背包中全部该燃料
4. 潜行点击 → 只消耗 1 个

**方式二：手持直接添加**
1. 手持燃料物品
2. 点击燃料槽或右键小人
3. 每次消耗 1 个

**卸下燃料：**
- 潜行点击状态卡可卸下限时燃料
- 永久燃料不可卸下

## 升级模块

> 模块槽位随 Tier 解锁（Tier 4 / 8 各开一个，共 4 个槽）。

### 掉落处理类

| 模块 | 效果 |
|---|---|
| 自动熔炼 | 矿石/原矿/沙子 → 熔炼产物（铁矿→铁锭） |
| 钻石散布 | 每次工作 ~2% 概率额外产出钻石 |
| 腐化之土 | 概率额外产出硫磺 + 腐化碎片 |

### 仓储压缩类

| 模块 | 效果 |
|---|---|
| 自动压缩 | 散装资源 9:1 压成方块（9 铁锭→1 铁块） |
| 超级压缩 3000 | 散装资源 160:1 压成附魔资源（160 煤炭→1 附魔煤炭） |

### 经济类

| 模块 | 效果 |
|---|---|
| 自动售卖漏斗 | 仓库满时自动 Vault 卖钱 |
| 简易漏斗 | 产出即时售卖（50% 价格） |
| 附魔漏斗 | 产出即时售卖（90% 价格） |

### 范围 & 存储类

| 模块 | 效果 |
|---|---|
| 范围扩展 | 工作面积 +5% |
| 小型储物箱 | 额外 +6 格仓库 |
| 中型储物箱 | 额外 +12 格仓库 |
| 大型储物箱 | 额外 +18 格仓库 |

### 如何装备模块

1. 管理员发放模块：`/minion upgrade 自动熔炼`
2. 手持模块物品
3. 右键小人打开仓库
4. 点击左侧模块槽（空槽）→ 装备成功
5. 点击已装备的模块槽 → 卸下（回到背包）

> **注意：** 同一类型模块不能重复装备。

## 图鉴系统

输入 `/minions` 打开仆从图鉴。

**功能：**
- **分类过滤**：顶行按钮按分类筛选（采矿/农业/伐木/战斗/钓鱼/特殊）
- **分页浏览**：每页展示多个仆从卡片
- **卡片信息**：已解锁等级 / 已放置数 / 总产出 / 下一级材料
- **收集进度条**：显示解锁进度
- **未解锁类型**：显示 ??? 与收集进度
- **点击查看配方**：聊天栏显示升级所需材料

## Collection 里程碑

每种资源独立计数，累计量跨过阈值时获得奖励。

**里程碑阈值：** 50 → 100 → 250 → 500 → 1000 → 2500 → 5000 → 10000

**奖励：**
- 金币奖励（第 n 个里程碑 = 基数 × n）
- 第 3/5/7 个里程碑额外奖励**仆从槽位 +1**

**查看进度：** `/minion collection`

## 收集解锁

部分仆从类型需要**累计收集对应产物达到一定数量**才能使用。

- 未解锁时图鉴显示 ???
- 放置时提示当前进度
- 管理员不受此限制

**示例：** 煤矿仆从需要累计收集 100 个煤炭才解锁。

## 离线收益

你下线后，仆从不会完全停止工作。

**结算时机：** 你上线时一次性结算闲置期间的产出。

**平衡机制：**
1. 仓库满 = 不再累计（防无限囤积）
2. 只按基础速度产出（不吃燃料/倍率加成）
3. 闲置时间从燃料剩余中扣除

**结算后会收到消息通知：**
```
【离线收益】煤矿仆从
· 煤炭 ×128
· 总计 128 件
```

## 稀有掉落

每种仆从都有专属的稀有掉落，概率通常在 0.3%~0.6%。

**特点：**
- 中奖时默认全服广播
- 稀有掉落可作为高阶升级材料（回流机制）
- 附魔金苹果、不死图腾、凋灵骷髅头颅等稀有物品

## 皮肤系统

右键小人打开仓库，点击右上角「皮肤」按钮切换外观。

**可用皮肤：**
- 默认皮肤
- 黄金皮肤
- 钻石皮肤
- 万圣节皮肤

每种皮肤有不同的头颅纹理，仅改变外观，不影响功能。

## 常见问题

### Q: 仆从不工作怎么办？
**检查清单：**
1. ✅ 范围内是否有可采集目标（矿石/作物/树木/怪物/水）
2. ✅ 仓库是否已满（满仓停工，头顶红字告警）
3. ✅ 范围内是否有玩家（`player-scan-radius` 半径内无人则休眠）
4. ✅ 燃料是否耗尽（无燃料仍工作，但不加速）

### Q: 仓库满了怎么办？
- 手动取出产物
- 装备「自动售卖漏斗」/「简易漏斗」/「附魔漏斗」模块
- 装备「储物箱」模块扩容

### Q: 如何查看仆从状态？
- 右键小人 → 信息卡显示速度/产量/范围/存储等
- `/minion stats` → 全局运行统计

### Q: 仆从被别人破坏了吗？
- 只有仆从主人和管理员可以操作
- 空岛模式下，同岛成员（岛主/队友）也可以操作

### Q: 如何获得更多仆从？
- 通过 Collection 里程碑解锁额外槽位
- 管理员可通过权限 `hcs.minions.limit.<n>` 调整上限

### Q: 仆从能被攻击吗？
- 仆从（盔甲架）不会被怪物攻击
- 仆从不会被爆炸破坏
- 只有潜行+右键才能拾取
