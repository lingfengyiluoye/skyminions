## 二、"为什么不能 100% 一比一"三个根本原因

### 1. 运行环境不同（最硬的约束）
Hypixel 的岛是他们自己托管的**永久加载空间**：仆从可以真实地一直干活。
我们是装在普通生存服里的插件——世界区块会卸载、玩家走了就没人在场。
如果强行模拟"永远在工作"，要么强制常加载（拖垮服务器），要么虚报产出。
→ 所以采用**闲置记账 + 上线结算**，并用三道锁保证它不会比在线更赚。
这一条属于"环境决定实现"，但体验目标已经拉平：**回来能收到一波**。

### 2. 经济生态不同
Hypixel 里仆从产出几乎是唯一货币来源，NPC 无限收购，官方团队随时调平衡。
我们是生存服插件，产出会和庄稼/刷怪塔/其他插件抢经济地位。
→ 因此有了：统一单价的保守定价、折价漏斗留作高级选项、
离线收益以仓储为天花板（防止"下线挂机最优"）。

### 3. 你的两条硬要求
- 「名字不一样」→ 精块/秘藏/催化剂这套原创命名体系；
- 「全中文」→ 所有 key 与文案中文化（连权限节点都改成了 minions.type.钻石仆从）。
这两条本身就和"一比一复刻"存在张力，目前取的是**机制对齐、皮相原创**。

## 三、如果你想更接近 Hypixel，建议的收敛顺序

| 优先 | 事项 | 理由 |
|---|---|---|
| ① | 补齐长尾类型 ~15 种（冰/雪/黏土/沙砾/花/蘑菇/仙人掌/甘蔗…） | 纯 YAML，成本低，内容厚度立刻上一个台阶 |
| ② | Storage 储物箱升级物品化 | 同时解决"扩容"与"离线天花板成长"两条线 |
| ③ | 两档折价漏斗（Budget 90% 即时 / Enchanted 99%） | 补齐 Hopper 家族最后一块 |
| ④ | 信息书并入头颅 lore（彻底去差异化） | 纯排版改动，但会失去独立状态卡的实时刷新优势，二选一 |
| ⑤ | Collection 等级树 L1–L9 | 中期工程 |
| ⑥ | 皮肤接入 HeadDatabase | 依赖外部插件 API |

## 四、明确不建议追平的点
- **岛屿常加载式真实离线生产**：在共享生存服上是性能灾难；
- **单一货币无限收购**：会摧毁生存服经济；
- **英文原名与 Enchanted 前缀**：与你"名字不一样"的要求冲突。
