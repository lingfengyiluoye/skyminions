# SkyMinions · Hypixel 式玩法与排版演进提案

> 目标：在现有架构（策略模式 / 强类型配置 / GuiText·GuiLayout 模板 / 两阶段落库）上，
> 大幅吸收 Hypixel SkyBlock 仆从系统的核心体验，同时保持 Folia 兼容与零硬编码槽位的既有约定。

---

## 一、Hypixel 体验的五个内核（我们缺什么）

| # | Hypixel 内核 | 现状 | 差距 |
|---|---|---|---|
| 1 | **离线也在生产**（下线回来一仓库资源） | 区块未加载=停产 | ❗最大体验差 |
| 2 | 数字成长**全程可见**（速度表/倒计时/满仓预警） | 信息卡已有 | 可再强化 |
| 3 | 收集(Collection)驱动一切解锁 | 有里程碑 | 缺"等级树"感 |
| 4 | 升级槽是**物品**而非开关（储物箱/漏斗都是插进去的道具） | 模块已是物品 ✓，但仓储扩容绑死在等级上 | 半差距 |
| 5 | 外观炫耀（皮肤社区共创） | 4 个内置皮肤 | 缺共创通道 |

## 二、玩法提案（按优先级）

### P0-1 离线收益结算 ⭐ 最优先 —— 重设计 v2（对齐 Hypixel 平衡内核）

> 设计红线：**离线永远不能比在线更划算，且不能成为"下线挂机"的最优解。**
> Hypixel 敢让离线生产，靠的是三道锁；我们逐一对应实现。

#### 三道平衡锁

| 锁 | Hypixel 的做法 | 我们的实现 |
|---|---|---|
| ① **仓储即天花板** | 仓库满=停产，离线收益自然封顶（通常只够 3~8 小时） | 结算前先算空闲格位 `Σ(maxStackSize-amount)`，产出按空位截断；**满仓=零补发** |
| ② **离线只吃基础速度** | （变体）燃料是"在线照料"奖励 | 离线结算**不吃燃料加速、不吃倍率、不吃完美布局加成**，只用等级冷却曲线 `cooldownTicksAt(level)` |
| ③ **真实时间消耗** | 燃料持续数天，离线也在烧 | 离线窗口从 `fuelTicks` 中等额扣除时长（燃料被真实消耗，长时燃料才有离线价值） |

#### 统一的时间语义（关键简化）

把「区块未加载」「半径内无人休眠」「玩家离线」统一为同一种状态：**闲置**。
闲置期不实时运算、不加载任何东西；当**仆从主人本人**下次上线时一次性结算整段闲置窗
（`now - lastActive`）。这样：

- 在线+玩家在旁 = 全速（燃料/倍率/布局加成全生效）
- 闲置 = 基础速度记账，等主人回来"收一波"
- `processMinion` 运行中持续刷新 `lastActive`（当前代码从未更新过它——必须补上，否则会重复支付）
- 休眠徽标 ⏾ 语义随之变为"闲置挂机中（上线结算）"，诚实且无歧义

#### 防滥用清单

| 风险 | 对策 |
|---|---|
| 下线刷钱优于在线玩 | 锁①②③叠加：离线单位时间收益 < 在线的 40%~60%（有燃料+倍率时差距更大） |
| 重复领取 | 结算第一步就原子推进 `lastActive` 并 markDirty（现有脏链路持久化），后补物品；崩溃最多少发绝不多发 |
| 岛员互相触发 | 只在**主人本人** PlayerJoin 时结算自己的仆从；岛员/访客不触发 |
| 上限爆炸 | `min(闲置秒, max-hours*3600)`，默认 24h；再加 `rate-percentage` 全局折减旋钮（默认 100%，服主可压到 50%） |
| Collection 刷分 | 离线产出照常计入 Collection（Hypixel 同款），但受同一仓储天花板约束 |

#### 数值推演（为什么"很大但不会失控"）

以圆石匠（product=圆石，单价 0.3）为例，36 格存储 ≈ 2304 单位天花板：

| 阶位 | 动作间隔 | 基础时速 | 离线填满仓储用时 | 一天离线实际所得 |
|---|---|---|---|---|
| III | 260t/13s | ≈277 个 | ≈8.3 h | ≈2304 个（早触顶）≈692 金 |
| VII | 200t/10s | ≈360 个 | ≈6.4 h | ≈2304 个 ≈692 金 |
| XI | 140t/7s | ≈514 个 | ≈4.5 h | ≈2304 个 ≈692 金 |

→ 无论离开 1 天还是 7 天，**单仆从离线收益都收敛到同一仓储上限**；
而在线挂机（燃料+倍率+即时售卖）收益是它的 3~5 倍。离线=保底，在线=主动收益，
定位健康。农夫/矿工同理（harvest-cap 越大触顶越快）。

#### 实现要点

- 新 `service/OfflineSettlement.java`：join 监听 → 收集主人仆从列表 → 逐个
  RegionScheduler 到仆从所在线程：算空闲格位 → 推进 lastActive → 生成聚合掉落
  （复用各策略新增的 `offlineYield(cfg, actions, rnd)`：统计型=product×cap×actions，
  钓鱼/牧民=模拟 roll 聚合，猎魔=通用池）→ addToStorage → collection.record →
  聊天栏摘要（Top3 物料 + 总件数）。
- 名牌/GUI：结算后信息卡追加一行 `{offline}` 可选行「▲ 离线收获 N 件」直至关闭 GUI。
- 配置：
  ```yaml
  offline-production:
    enabled: true        # 总开关
    max-hours: 24        # 单次结算最长回溯
    rate-percent: 100    # 基础速度折扣（保守服主可设 50）
    min-seconds: 180     # 低于此闲置不结算（防频繁上下线噪音）
  ```
- 依赖说明：仓储天花板初期直接用「等级解锁格数」；第 3 期储物箱物品化落地后
  天花板随投资成长——这正是 Hypixel 让玩家心甘情愿做储物箱升级的动力闭环。


### P0-2 催化剂类「产量倍率」燃料（第二维度）
- Hypixel 里燃料分两轴：**速度%** 与 **产量倍率**（Catalyst 类）。我们只有速度轴。
- 新增 `FuelValue.multiplier` 字段（默认 1.0）：如 `GLOWSTONE_DUST ×1.5 / 30min`、
  `AMETHYST_SHARD ×2.0 / 15min`（数值进 config.yml `fuels:` 段，代码零改动读表）。
- `WorkOutcome.drops` 出仓前乘 multiplier；GUI 信息卡新增一行 `{mult} 倍率中`。

### P0-3 状态徽标 + 名牌三态（排版即信息）
- 名牌规则对齐 Hypixel 的 `[Lv] 名字` 并叠加状态色：
  - 工作中：`▶ 圆石匠 III`（灰字）
  - **满仓停工**：`⚠ 圆石匠 III`（黄字+红后缀）
  - 无人休眠：`⏾ 圆石匠 III`（深灰）
  - **完美布局**：追加金色 `✦`（见 P1-1）
- 实现：`refreshStatus` 已有状态缓存机制，扩一个枚举即可，零额外性能。

### P1-1 完美布局检测（社区最爱的"排版玩法"正式化）
- 每类型定义"理想摆法"谓词（矿工：范围内矿石占比≥80%；农夫：满耕地+四水；
  钓鱼：5×5 水；圆石：理想布局开且生成点就位）。
- 每 30s 低频扫描一次（region 线程，结果缓存在 Minion）。
- 达成：名牌 `✦`、信息卡新增一行 `<gold>✦ 完美布局 +10% 产量</gold>`、
  图鉴卡片同步标记。让"怎么摆"第一次有了回报。

### P1-2 仓储扩容「物品化」（对齐 Hypixel Small/Medium/Large Storage）
- 新增三种升级物品：小型储物箱(+9)/中型(+18)/大型(+27)格，插入**模块槽**生效
  （占用一个模块位——Hypixel 同款取舍：要容量还是要功能）。
- `Minion.unlockedSlots()` 改为 `等级基础 + storageBonus`；GUI 锁定格随 bonus 动态解锁。
- 旧档兼容：无此物品行为不变。

### P1-3 折价即时售卖漏斗（两档化）
- 现 autoSell 是布尔。对齐 Hypixel Budget/Enchanted Hopper 双档：
  - `auto_seller`（现有）：仓满才卖，**100% 价**
  - 新 `enchanted_seller` 模块：**实时卖 90% 价**（不等仓满，资金流快但亏 10%）
- 经济上形成"现金流 vs 收益"的真实抉择。

### P1-4 稀有掉落「用途回流」
- 现在各类型 rare-drop 只是卖点钱。Hypixel 的精髓是稀有物是**下一级合成的原料**。
- config 已支持多材料配方 → 把各类型 rare-drop 设为其 Tier VIII+ 配方材料之一，
  即刻形成"刷稀有→冲顶阶"的循环，零代码改动，只改 config.yml。

### P2-1 Collection 等级树（L1~L9）
- 里程碑从"线性阈值列表"升级为每资源 9 级：每级解锁
  （配方片段 / +1 槽位 / 称号 / 全局微 buff）。
- `/minions` 图鉴第二页展示等级树进度条。

### P2-2 顶阶 Tier XII 特殊合成
- XII 不再用材料堆：要求 `XI 本体 + 该类型稀有掉落×N + 全服限定物`
  （如龙蛋/下界之星），制造服务器级目标。

### P2-3 轻量害虫（花园 Pest 微缩版）
- 农夫/牧民工作时有 0.5%/次 概率在范围刷 1 只"害虫"蝙蝠/蚕虫（自定义名），
  存活期间该仆从产量减半；玩家击杀返还 60s 双倍。给"挂机"加入手动介入点。

### P2-4 全服事件日
- cron 式配置：周末「仆从狂欢」全场燃料效果 ×2、节日双倍稀有率。
- 公告横幅 + 信息卡临时行。实现为 `EconomyService.priceMultiplier` 同款的全局系数。

## 三、GUI / 排版提案

### 3.1 主界面重排（54 格，向 Hypixel 原版靠拢）
```
现行:  0燃料 1▒ 2▒ 3信息 4头颅 5升级 6▒ 7皮肤 8▒
       9..44 存储(36)
       45▒46▒ 47模1 48模2 49收 50售 51布 52拾 53关

提案:  0燃料 1▒ 2状态 3▒ 4头颅 5信息 6▒ 7升级 8皮肤   ← 升级移回顶行右侧(原版位)
       9..44 存储(36，锁定格浅色玻璃+悬停提示"Tier X 解锁")
       45▒46▒ 47模1 48模2 49收 50售 51布 52拾 53关      ← 不变
```
变化点：①新增 **2 状态卡**（燃料余时条形 + 下次动作倒计时 + 今日产量，替代纯装饰）；
②信息书与升级互换更贴近原版阅读顺序。全部经 `gui.yml layout` 重排，**不改 Java 常量**。

### 3.2 信息卡图表化
- `{rate}` 旁加 Unicode 迷你柱状图 `{chart}`：最近 12 小时产量分布（`▁▂▄▆█`）。
- 需要 ring buffer 统计（每仆从 24 long，内存可忽略），由 performWork 累计。

### 3.3 颜色语言规范（写入 AGENTS.md）
`绿=开启/充足 · 红=停工/不足 · 金=可升级/里程碑 · 灰=未解锁 · aqua=模块 · 黄=警告`

### 3.4 存储翻页（配合 P1-2 扩容超 36 格时）
底行 49 收集钮左右出现 ◀ ▶ 小箭头，翻页显示第 37~63 格；数据层仍是同一 Inventory 的逻辑分区。
