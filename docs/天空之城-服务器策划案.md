## 1. 项目概述

### 1.1 一句话定位

**「一座漂在云海上的城市，每个玩家拥有一座会成长的浮空岛——采集、养成、狩猎、下副本，从一把木剑打到弑星。」**

### 1.2 目标与愿景

- **长线养成**：不做删档赛季，玩家资产永久保值，以季度大版本持续供给新目标。
- **单机化的多人体验**：私人空岛保证"我的地盘我做主"，公共区域与副本保证社交密度。
- **轻商业化**：收入以覆盖服务器运营成本为目标，付费只卖外观与便利、不卖数值，零氪玩家可体验完整内容。
- **中文社区标杆**：全量中文化（GUI/物品/剧情/提示零英文残留），低延迟国内体验。

### 1.3 目标用户画像

| 人群 | 特征 | 核心诉求 |
|---|---|---|
| Hypixel SkyBlock 中文玩家 | 想要同类玩法但受限于延迟/语言 | 同级深度 + 低延迟 + 全中文 |
| MC 生存服资深玩家 | 玩腻原版，追求目标感 | 清晰的成长线与毕业追求 |
| 休闲学生/上班族 | 在线时间碎片化 | 仆从离线产出、每日短目标 |
| 收集党/成就党 | 图鉴、稀有掉落驱动 | 掉落表透明、保底机制 |
| 小团体/公会 | 开黑社交 | 组队副本、公会竞赛 |

### 1.4 与 Hypixel SkyBlock 的关系

**框架致敬、内容原创、数值重做。** 保留其被验证的核心骨架：空岛 + 技能 + 仆从 + 猎杀 + 副本 + 双市场经济；但世界观、怪物、装备、地图、任务全部原创，避免侵权并做出本地化差异。

### 1.5 差异化竞争力

1. **仆从系统即卖点**：基于现有 SkyMinions 插件（7 种工作策略、燃料/升级/自动售卖/GUI 模板化已落地），开服即可用且体验领先。
2. **数值更友好**：Hypixel 毕业周期以年计，本项目按 6 个月设计毕业主线，月卡党可追平。
3. **新手曲线更陡的上升反馈**：首日即可解锁第一只仆从 + 第一件稀有装备。
4. **反脚本经济治理前置设计**：货币水槽、行为审计、掉落保底在立项阶段就进文档。

## 2. 核心玩法循环

### 2.1 主循环

```
        ┌────────────────────────────────────────────┐
        │                                            │
        ▼                                            │
   [采集/生产]──→[积累资源]──→[合成强化]──→[挑战 PvE]─┤
        ▲            (金币/材料)   (装备/附魔)  (猎杀/地牢) │
        │                                            │
        └────←───[解锁新内容]←──[获得更强装备/属性]←────┘
              （新岛屿/新技能上限/新副本层）
```

### 2.2 目标嵌套（防流失的关键）

| 时间尺度 | 目标示例 |
|---|---|
| 单次在线（15 分钟） | 完成一次猎杀委托 / 收一轮仆从产物 / 刷一层地牢钥匙材料 |
| 每日 | 日常委托 3 件套（采集/战斗/生活各一）、黑暗拍卖会（周三/周日） |
| 每周 | 公会周任务、世界 Boss 轮换、限时活动节日 |
| 每月 | 市长选举、技能冲榜、新装备图纸收集 |
| 季度 | 新区域/新副本层大版本、全服事件 |

### 2.3 玩家动机覆盖（Bartle 四类型）

- **成就者**：技能满级、图鉴 100%、装备毕业、SkyBlock 等级榜。
- **探索者**：隐藏房间、谜题房间、彩蛋 NPC、秘密配方。
- **社交者**：公会、双人岛屿、合作 Boss、交易市场。
- **杀手型（PvE 向转化）**：竞速榜单（地牢通关计时）、伤害统计排行。

## 3. 世界观与地图结构

### 3.1 世界观设定

远古时代一颗陨石击碎了大陆，残骸悬浮于无尽云海之上，形成「天空之城」。城中「守望者议会」守护着维系浮岛不坠的**星辰核心**；而侵蚀世界的「虚蚀」正从裂隙中渗出。玩家的身份是议会招募的**拾星者**：经营自己的浮空岛，深入各地净化虚蚀，最终直面陨星深处的存在。

> 叙事原则：轻叙事重目标。所有剧情通过 NPC 对话 + 物品 Lore + 区域氛围呈现，不做强制过场。

### 3.2 区域总览

| 区域 | 定位 | 对应 Hypixel 参考 | 解锁条件 |
|---|---|---|---|
| 出生浮岛·晨曦屿 | 教学+私人空岛发放 | 私人岛屿 | 进服即有 |
| 云枢城 | 主城枢纽：银行/集市/拍卖行/NPC | Hub | 教学完成 |
| 农耕谷 | 农业技能区、作物收购 | The Farming Islands | 农业 1 级 |
| 矿脉深井 | 采矿+粉末系统 | Dwarven Mines | 采矿 5 级 |
| 晶核洞天 | 后期采矿、稀有矿脉、 commissions 式委托 | Crystal Hollows | 采矿 25 级 + 门票 |
| 苍翠林地 | 伐木技能区 | Foraging Island（新版） | 伐木 5 级 |
| 渔人码头 | 钓鱼+海洋生物图鉴 | Dock/Fishing | 钓鱼 3 级 |
| 绯红荒原 | 高级战斗区、五大据点势力 | Crimson Isle | 战斗 24 级 |
| 虚空裂隙 | 末期单人挑战位面 | The Rift/The End | 战斗 40 级 |
| 星陨回廊 | 副本入口（见 §5.3） | Dungeons/Catacombs | 战斗 15 级 + 钥匙 |
| 渊喉海沟 | 团队首领玩法（见 §5.4） | Kuudra | 战斗 30 级 |
| 浮云竞技场 | 活动/PvP 可选区（软开启） | — | 后续版本 |

### 3.3 私人空岛（核心资产）

- **初始规格**：128×128 浮空地块 + 新手小屋蓝图；随 SkyBlock 等级扩容至 256×256。
- **岛屿功能建筑**（逐步解锁）：仆从槽位架、仓库箱子阵列、附魔台/炼金台、岛屿传送门（好友访问）、宠物放养区。
- **岛屿等级**：由放置的功能方块与建筑评分决定，提供小幅全局加成（≤5%），鼓励建造但不逼肝。
- **双人合租**：后期开放「共岛契约」，最多 3 人共享一座岛（信任权限分级：访客/管家/共同所有）。

## 4. 成长系统

### 4.1 属性体系（所有装备/技能/宠物的公共语言）

| 属性 | 说明 |
|---|---|
| 生命 HP | 基础 100 起 |
| 防御 DEF | 有效生命 EHP = HP × (1 + DEF/100) |
| 力量 STR | 近战伤害系数，每点 +1% 武器基础伤害 |
| 智力 INT | 法力池上限与法术伤害基数 |
| 敏捷 AGI | 攻速与移速微调 |
| 幸运 LUK | 稀有掉落权重微调（有日上限防滚雪球） |
| 暴击率 / 暴伤 | 默认 30% / +50%，可堆叠至上限 100% / +300% |
| 攻速 AS | 次/秒，上限 2.5 |
| 吸血 / 真伤 / 穿透 | 高级词缀，来源受限 |

### 4.2 技能系统（10 项，上限 50 级）

| 技能 | 升级来源 | 关键节点奖励（示例） |
|---|---|---|
| 农业 | 收获成熟作物 | Lv15 解锁南瓜/瓜类；Lv25 解锁特供种子 |
| 采矿 | 采掘矿石（模拟采集计数） | Lv12 解锁深井传送；Lv30 解锁晶核洞天资格 |
| 战斗 | 击杀任意敌对生物 | 每 5 级 +2% 伤害；Lv15 解锁星陨回廊 |
| 伐木 | 连锁砍树（自动补种不计） | Lv20 解锁硬木树种（高级材料） |
| 钓鱼 | 钓起任何渔获 | Lv20 解锁海怪事件；Lv35 解锁渊喉鱼饵 |
| 附魔 | 附魔台操作/拆解附魔书 | Lv20 解锁终极附魔抽取台 |
| 炼金 | 酿造药水 | 药水时长 +2%/级 |
| 木工 | 合成家具/装饰方块 | 解锁岛屿装饰配方线 |
| 驯兽 | 携带宠物获得经验 | 宠物经验 +1%/级 |
| 铭刻 | 制作符文石/饰品 | 解锁高阶饰品合成 |

经验曲线公式与分级表见 §8.2。每项技能满级奖励专属称号 + 传说级饰品一件。

### 4.3 收集图鉴（Collections）

- 按类别聚合（武器/护甲/材料/鱼类/农作物…），记录累计获取数量。
- 里程碑奖励：达到阈值解锁**合成配方**（这是大量中阶配方的唯一来源，复刻 Hypixel 的正确设计）。
- 图鉴进度计入 SkyBlock 等级；全图鉴 100% 给予「万象收藏家」称号与动态披风。

### 4.4 仆从系统（Minions）★ 已有实现基础

直接以现有 **SkyMinions 插件**为基础扩展（架构约定沿用 AGENTS.md）：

| 设计项 | 规格 |
|---|---|
| 类型 | 矿工/农夫/伐木工/渔夫/猎魔/炼金/附魔 等 10 类（现有 7 策略 + 新增渔夫/铭刻/炼金） |
| 等级 | Tier 1–12，升级走 Hypixel 式 3×3 合成格（本体 + 材料合成下一 Tier） |
| 产出 | 模拟采集：基础间隔 × (1 − 加成)；信息书展示速度/件每小时/范围/存储/稀有掉落 |
| 燃料 | 有时限增益（如 48h 双倍速），到期自然回落 |
| 自动售卖 | 仓库连接售卖点后满仓自动折价出售（折价率 80%，保护线下市场） |
| 上限 | 基础 5 格，随 SkyBlock 等级扩至 20 格 |
| 休眠 | 玩家 `player-scan-radius` 内无人则停产（省性能，鼓励在线挂机在岛） |
| 存储 | 满仓停工 + 名牌红字告警，取货恢复（现有逻辑保留） |

技术注意：全局调度器 O(n)+O(1) 短路、触碰方块逻辑委派 region 线程（Folia 兼容）、DB 写指数退避重试——均已在 SkyMinions 实现，直接继承。

### 4.5 宠物系统（Pets）

- 等级 1–100，经验来自携带时的对应行为；驯兽技能提升获取率。
- 品质：普通→神话；同名宠物品质决定属性倍率。
- 示例：幼星龙（战斗系，暴伤加成）、石灵（采矿速度）、麦穗精（农业双收概率）、深海鲸（钓上宝箱率）、金蟾（NPC 收购价 +x%）、影猫（移速+夜视）。
- 配套：宠物糖果（直升经验）、进化道具、自动携带规则（进入矿区自动切换石灵）。

### 4.6 饰品/护符系统（Accessories）

- 独立饰品背包，格子数随 SkyBlock 等级增长（初始 9 格 → 满级 45 格）。
- **同名系列只计最高一件**（防堆叠），系列覆盖：力量/防御/暴击/幸运/采集/钓鱼/经济 七大方向 × 五个品级。
- **力量石（Power Stone）**：选择一种全局属性倾向（如「鹰眼」+暴伤 −防御），饰品背包整体生效，后期构筑自由度来源。

### 4.7 附魔系统

- 普通附魔：改造原版附魔为自定义体系（锋利→碎星 I-V…），附魔台等级需求 + 书本合成。
- **终极附魔**：武器/护甲各仅一个终极槽（如「无双：对满血敌人 +35%」「不屈：低于 30% 血减伤 20%」），来源为地牢/猎杀掉落书。
- 附魔冲突矩阵：互斥组合不可共存（防止 Hypixel 式数值爆炸）。
- 附魔拆解台：拆书返还部分材料（附魔技能经验来源之一）。

### 4.8 重铸（Reforge）

- 消耗矿物锭 + 金币随机重掷前缀：武器（碎星/迅影/嗜血/裁决…）、护甲（磐岩/轻羽/圣辉…）、工具（丰饶/矿脉…）。
- 前缀强度 = 基础值 × 稀有度系数（§8.3）。
- 「重铸锁定券」可锁 1 条词条再掷其余（深渊掉落，回收货币）。

### 4.9 精华与升星（Essence & Stars）

- 副本/猎杀产出的**魂玉**分五系：亡灵/蛛丝/霜狼/虚空/狱炎。
- 装备消耗对应魂玉 + 金币升星 ★1–★5，每星 +4% 全属性（最高 +20%）。
- 精华商店同时出售地牢装备外观皮肤与旧版装备兑换（长线回收）。

### 4.10 SkyBlock 等级（角色综合等级）

- 汇总技能/图鉴/宠物/地牢职业/活动等经验折算成 1–500 级角色等级。
- 解锁：饰品格子、仆从槽、岛屿面积、称号、入场资格（渊喉 T3 需等级 ≥120 等）。
- 记分板常驻显示，是「账号厚度」的直观指标。

### 5.3 星陨回廊（七层副本）

- **入场**：星陨钥匙（低层合成可得，高层需前层掉落部件）。
- **队伍**：1–5 人，五职业分工：

| 职业 | 定位 | 核心技能示例 |
|---|---|---|
| 狂战 | 近战输出 | 旋风斩、狂化（攻速激增） |
| 奥术师 | 法术输出 | 星火弹、奥术屏障（替身） |
| 神射手 | 远程输出 | 箭雨、标记（全队增伤） |
| 圣愈者 | 治疗 | 圣光涌动、复活光环 |
| 壁垒 | 坦克 | 嘲讽、壁垒墙（放置临时掩体） |

- **结构**：程序化拼装的房间链——战斗房/谜题房（机关解密）/陷阱房/Boss 房；隐藏房间藏精华与宝箱。

### 5.5 世界 Boss 与动态事件

- 每周末轮换：陨星坠地（矿区采集事件）、雾潮入侵（主城防守波次）、深海异动（全服钓鱼竞赛）。

## 6. 经济系统

### 6.1 货币体系

| 货币 | 性质 | 来源 | 主要去向 |
|---|---|---|---|
| 金币 | 主流通币 | NPC 收购/任务/副本/活动 | 装备市场、手续费、重铸、银行 |
| 魂玉 | 装备绑定强化材料 | 地牢/猎杀 | 升星、精华商店 |
| 星辉 | 账号绑定积分 | 在线时长/活动/商城赠送 | 公益商店（外观/QoL） |
| 云晶 | 付费钻石 | 充值 | 商城：外观与便利类商品（§11.1） |

### 6.2 水龙头与水槽（必须平衡）

**金币来源（Faucet）**：NPC 收购（定价随市场波动系数调整）、任务奖励、地牢/猎杀掉落、活动结算、银行利息（0.1%/日，按账户等级设计息上限）。

**金币回收（Sink，通胀治理核心）**：

| 回收口 | 数值 |
|---|---|
| 拍卖行成交税 | 5% |
| 拍卖行上架费 | 2%（最低 100 金） |
| 集市成交税 | 2% |
| 重铸费用 | 按稀有度 1 万–50 万/次 |
| 升星金币消耗 | ★5 全程约 800 万 |
| 修理/传送/门票 | 长尾小额高频 |

**监控红线**：全网金币存量周环比 > 8% 时，自动下调 NPC 收购价系数并公告；连续两周超标触发专项回收活动（限时高价回收冗余材料）。

### 6.3 集市（Bazaar，原材料股市）

- 订单簿式：即时吃单买/卖 + 挂单；覆盖全部原材料与常见成品。
- 每商品展示： instant buy/sell 价、7 日走势图、成交量。
- 挂单占用格子有限（20 格），防巨鲸控盘；单笔挂单金额上限。
- 价格形成完全由玩家订单驱动，NPC 收购价 = 集市中间价的 70%（动态跟随，封顶封底）。

### 6.4 拍卖行（AH，成品与稀有品）

- 一口价 + 竞拍两种模式，展示时长 24/48 小时。
- 仅稀有度≥稀有 或 含特殊 NBT 的物品可上架（防止集市功能重叠）。
- 数据入库审计：每笔成交记录买卖双方、物品指纹（UUID）、价格，供风控回溯。

### 6.5 反脚本反工作室（经济安全前置设计）

| 手段 | 说明 |
|---|---|
| 行为基线 | 每账号每小时各类收益阈值（金币/技能经验/掉落数），超限进入审查队列而非直接封禁 |
| 采集熵检测 | 固定点位/固定间隔/无视角变化的采集模式识别 |
| 交易图谱 | 异常资金流向图分析（新号→中间号→大号洗钱路径） |
| 硬件指纹 | 多账号关联识别（同 IP/同设备簇批量注册预警） |
| 经济审计台 | 管理端实时仪表盘：货币存量/物价指数/可疑账号列表 |

### 6.6 起始经济参数

- 新号出生：250 金币 + 新手礼包（含 7 日保险箱免手续费券）。
- 第一只仆从成本约 5,000 金（教学任务补贴 60%）。
- 首件史诗装备市场参考价：15 万–30 万（公测第 1 个月目标区间）。

## 8. 数值设计与示例

### 8.1 核心公式

```
近战伤害 = ⌊ 武器基础 × (1 + STR/100) × (1 + 战斗等级 × 0.4%)
           × Σ(附魔倍率) × 暴击判定(×(1+暴伤)) × rand(0.95~1.05) ⌋
实际承伤 = 伤害 × 100 / (100 + 目标DEF)
EHP     = HP × (1 + DEF/100)
```

- 设计锚点：同预算下「攻击流」与「防御流」EHP/TTK 曲线差 ≤15%；暴击流方差大、期望持平。
- 怪物侧同样使用该公式（怪物也有 DEF），保证一致性可推演。

### 8.2 技能经验曲线（示例值，可调）

单级所需经验 `XP(n) ≈ round(60 × n^1.9)`，满级（50）累计约 **256 万**。

| 5 | 1,280 | 3,400 |
| 10 | 4,800 | 19,000 |
| 15 | 10,300 | 64,000 |
| 20 | 17,800 | 148,000 |
| 25 | 27,200 | 295,000 |
| 30 | 38,500 | 520,000 |
| 35 | 51,400 | 835,000 |
| 40 | 66,400 | 1,260,000 |
| 45 | 83,000 | 1,830,000 |

节奏基准：休闲玩家（日均 2h）单一技能满级约 3 周；十技能全满约一季（含加成期）。

## 9. UI/UX 与客户端体验

### 9.1 GUI 规范（沿用项目既有约定）

- 全量**中文化**：GUI 文案、消息、名牌零英文残留。

- 卡片式排版：头颅居中锚点、`▬` 分节线、对比式按钮（当前→下一级）。

### 9.2 新手引导流程（目标 ≤10 分钟）

```
登录晨曦屿 → 守望者凯拉对话 → 三步教学（砍树→合成→交任务）

```

- 所有引导步骤可跳过（老玩家回流友好），跳过后仍可从手册补课。

- 记分板：金币 / SkyBlock 等级 / 当前区域在线人数 / 活动倒计时（可 `/hud` 自定义开关）。

- 数值透明：任何 Buff 生效时在 Tab 列表面板显示汇总明细。

**C. 无现成插件可满足 → 必须自研（skyc-* 承接）**

| 模块 | 为什么没有现成方案 | 工作量估计 |
|---|---|---|
| skyc-market 集市订单簿 | Hypixel 式 Bazaar 撮合引擎无成熟公开实现（市面「bazaar」多为摆摊/箱店） | 25–40 人日 |
| skyc-combat 伤害管线 | STR/暴击/真伤/穿透统一公式要贯通装备+技能+宠物+饰品，AuraSkills 属性体系承载不了 | 15–25 人日 |
| skyc-minion 仆从 | ——已有 SkyMinions（自研完成，直接迁移扩展） | ✅ 已完成 |
| skyc-collection 图鉴 | 「累计数量→里程碑解锁合成配方」模型现成成就插件不支持 | 10–15 人日 |
| skyc-accessory 饰品+力量石 | 独立槽位 UI + 同名系列去重 + 全局力量石切换，无现成实现 | 12–18 人日 |
| 升星/魂玉 + 重铸 | 词条随机池与星级成长属深度定制 | 10–15 人日 |
| skyc-level 综合等级 | 多系统经验折算聚合，纯业务逻辑 | 5–8 人日 |
| 猎杀委托 Slayer | 「付费接取→区域召唤→50 次保底计数」流程无现成插件 | 10–15 人日 |
| 市长选举+活动调度 | 全服 Buff 月度切换 + 投票 GUI + 活动日历触发器 | 8–12 人日 |
| 银行利息 | XConomy 无利息机制 | 2–3 人日 |
| 行为基线审计台 | 收益阈值/交易图谱/风控仪表盘是运营级定制，通用反作弊不覆盖经济侧 | 15–25 人日 |
| skyc-economy 审计流水 | 现成经济插件流水粒度达不到对账级 | 12–18 人日 |

自研合计 ≈ **124–199 人日**（不含已完成仆从），与 §12 排期 P0–P2 两个开发 × 6 个月的人力匹配。

**第三方许可成本小结**：以上绝大多数免费开源；付费集中在 MythicMobs Premium（可选）、MythicDungeons、EcoPets/EcoEnchants 扩展、可选 Vulcan——一次性/年费合计约 **$100–200（¥700–1,500）**，计入 §11.2「插件授权摊销」。

**选型四原则**：
1. 免费开源优先；付费插件必须在 staging 实测 + 作者近 6 个月有更新才可采购。
2. **核心循环（市场/战斗/仆从/图鉴）零依赖闭源插件**——闭源件只许出现在外围（地牢实例/宠物/反作弊），保证随时可替换。
3. 禁止用 Skript 编写核心系统（性能与可维护性）；仅允许运营活动的临时小逻辑。
4. 所有插件版本锁死，升级前必跑 §10.5 回归清单。

## 11. 商业化与合规

### 11.1 付费点设计（轻量化）

**商业定位**：轻商业化——收入目标是**覆盖服务器成本并留出小额版本开发基金**，不追求利润最大化。付费只出售外观与便利，不出售金币、属性、经验与毕业装备；按项目决策不受 Minecraft EULA 约束，但设计上主动保持克制，以保护社区口碑与长线留存。

| 付费项 | 内容 | 定价参考 |
|---|---|---|
| 赞助等级·云侠（永久） | 专属披风/帽子、岛屿内 `/fly`、满服优先排队 | ¥68 |
| 赞助等级·云尊（永久） | 云侠权益 + 动态披风、宠物皮肤、额外饰品外观栏、每日星辉补贴 | ¥168 |
| 月卡 | 每日领 300 云晶 + 星尘饼干效果（经验 +15%、离线收益照常运转）；饼干可在拍卖行流通，零氪玩家可用金币获得同款增益 | ¥25/月 |
| 云晶商店 | 外观套装、动作表情、岛屿装饰包；便利券（传送券/修理锤/背包扩容/重铸锁定券），同类便利券同步在星辉商店限量兑换 | ¥6 = 60 云晶起充 |

> 设计底线：不设抽奖、不开金币直购、不卖成长补给；付费体验上限是「更快的便利与更好看」，不是「更强」。

### 11.2 收支模型（保本测算）

| 项目 | 月成本估算 |
|---|---|
| 服务器托管（独立机或 3 台云主机） | ¥600–1,500 |
| 高防 IP / DDoS 防护与带宽 | ¥100–400 |
| 域名 / 备案 / 杂项 | ≤ ¥50 |
| 插件授权摊销（反作弊等年费 ÷12） | ¥50–150 |
| 美术 / 建筑外包摊销 | ¥300–800 |
| **合计** | **约 ¥1,100–2,900/月** |

保本线测算：MAU 1,000 人 × 付费转化 8–12%（80–120 人）× 人均 ¥25/月 ≈ 月流水 ¥2,000–3,000，即可覆盖成本；MAU 2,000 人后产生 50% 以上结余，作为季度版本的美术/外包开发基金。人力为主理人兼职投入，不计入刚性成本。

### 11.3 合规说明

按运营决策，本方案不引入 Minecraft EULA 对付费内容的限制；因付费范围已收窄至外观与便利，实际风险敞口较小，残余平台投诉风险由运营方知悉并承担。中国大陆公开收费运营仍涉及著作权授权/资质与收款渠道（第三方支付商户资质）问题，需运营方自行评估处置。个人信息收集遵循《个人信息保护法》最低必要原则（仅 UUID 与运行必需日志）。

### 11.4 KPI 指标

| 指标 | 目标 |
|---|---|
| 次留 / 7 留 / 30 留 | ≥ 45% / 25% / 12% |
| 人均在线时长 | ≥ 90 min |
| 付费转化（占 MAU） | 8–12% |
| 人均月消费 | ¥25–40 |
| 财务健康 | 月流水 ≥ 月成本 × 1.3；结余率 ≥ 30% 投入下版本开发 |
| 经济健康 | 物价指数周波动 < 10%；金币存量周环比 < 8% |
| 内容消耗速度 | 版本毕业人数占比 < 20% 时上线下一大版本 |
